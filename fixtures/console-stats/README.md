# console-stats 合成記憶庫

仿主控台 `buildVaultStats`(主控台 repo `src/main/vault-stats.ts`,2026-11-22 加入 `專案ID`)目前輸出格式的合成資料,用於 stats 契約測試。全部是虛構內容,不含真實路徑或使用者資料。

涵蓋:
- `專案ID` 與 `專案` 同序同長度;兩個節點在**同名不同 ID** 的專案(`app`),不得連成同專案線。
- `null` 欄位:`角色`、`完成率`、`頭像路徑`、`立繪路徑`、`session.後台`、`session.sessionId`、`session.CLI有紀錄`。
- 舊版節點:沒有 `專案ID`(退回用名稱分組)。
- `協作`、`同席` 各一筆;`圖像目錄` 為空字串。
- `總管`(2026-11-22 主控台新增):每個節點的 `true/false`;合成甲為總管。
- `專案表`(2026-11-22 主控台新增):根層 `{ 專案ID: { 名稱, 類型: "git" | "資料夾" } }`;兩個 `app` 是 git,`共用庫` 是非 git 資料夾。舊版節點沒有 `專案ID`,不在專案表內。
