- 安裝檔**未簽章**(沒有程式碼簽章憑證),安裝時 Windows 可能顯示 SmartScreen 提示。
- `release\` 根目錄的舊安裝檔與不完整的 `win-unpacked` 被主控台鎖住(`app.asar` EBUSY),無法覆寫或清除;新版一律輸出到 `release\next`。主控台關閉後可清掉 `release\` 根目錄的舊檔。
- 主控台第一版還不寫會議紀錄的 `產出` 與決策的 `來源會議`;寶庫已能讀取與顯示,等主控台補上後再做實機驗證。
